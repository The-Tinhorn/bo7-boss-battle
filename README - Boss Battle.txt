BOSS BATTLE BETA -  by Tinhorn
Infinite Warfare style boss battles for Black Ops 7 Zombies on the Kronos client.
SUBSCRIBE TO TINHORN :)  youtube.com/@TheTinhorn

WHAT YOU NEED
- Kronos v1.41
- The "BO3 HUD kit" mod that comes with Kronos enabled

INSTALL
1. Close the game.
2. Copy the "boss_battle" folder from this zip into your Kronos mods folder
3. Start the game and make sure "Boss Battle" is enabled in the Kronos Mods menu.

UPDATING TO A NEW TEST BUILD
1. Close the game completely.
2. Copy the new files over the old ones.
3. Delete the .gscc files inside boss_battle\scripts\compiled
4. Start the game

UNINSTALL
Disable it in the Kronos Mods menu, or delete the boss_battle folder.

HOW TO PLAY
- Pick any map and choose the "Boss Battle" tile. It uses the Directed tile
- YELLOW portal: the map's boss fight at round 40.
- RED portal: the same fight at round 100.
- GREEN portal: relics. Stand next to it and a relic list appears on the left.
     Use (interact)        = next relic
     Crouch + Use          = switch the selected relic on / off
  If any relic is on when you press Use on the yellow or red portal, the fight is CURSED and uses
  the game's Cursed boss tuning. With no relics on it uses the standard tuning.
- The fight timer and your personal best (PB) show in the top-right corner. PBs are kept per
  map, per round (40 / 100) and standard vs Cursed.


KNOWN ISSUES
- Cursed fights (relics on) are barely tested: report whether each relic actually does something.
- Wonder weapons from other maps may be missing effects off their home map.(Kronos issue)
- If you run into any loading problems use default operators/weapon skins
- Rex Infernus might be buggy, if you crash remove under barrels from BO6 Weapons
