# Boss Battle for BO7 Zombies (Kronos)

Infinite Warfare style boss battles for Black Ops 7 Zombies on the Kronos client, on every launch map.
By [Tinhorn](https://www.youtube.com/@TheTinhorn) — subscribe :)

Pick the **Boss Battle** tile (it takes over Directed). You spawn in a zombie-free gear-up area with maxed money,
Pack-a-Punch, Wunderfizz, crafting table, Arsenal, GobbleGum, Mystery Box, armor, every wonder weapon and ultra
Aether Tools. Use the
**YELLOW** portal (round 40) or **RED** portal (round 100) to start the map's boss fight, with a timer and personal best.
The **GREEN** portal toggles relics for a Cursed fight.

## Install

Download `BossBattle-test-<version>.zip` from [Releases](../../releases), close the game, and copy the `boss_battle`
folder into `<game folder>\kronos\mods\`. Then enable **Boss Battle** in the Kronos Mods menu. When updating, copy
the new files over the old ones, then delete the `.gscc` files in `boss_battle\scripts\compiled`.

Boss Battle needs the **BO3 HUD kit** mod that ships with Kronos (for the timer and relic menu). Built and tested on Kronos v1.41.

How to play and known issues: [`README - Boss Battle.txt`](README%20-%20Boss%20Battle.txt).

## Reporting a problem

Tell Tinhorn the map, the portal, whether relics were on and what happened, and send `<game folder>\poi_reg.log`
and `<game folder>\kronos\boss_battle\state.json`, copied right after the problem and before starting the game again.
